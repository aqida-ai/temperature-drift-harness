# Evidence index — v0.4.1

This release preserves selected original gates, commitment files and figures.
Their historical claim flags describe scientific authorization, not whether this
repository is public. The original failed instrument gate remains unchanged.
The full raw experiment archive and private governing theory sources are not bundled.
Manuscripts identify unbundled sources explicitly; those labels are not download links.
The saved Step-0 hypotheses were initially unassigned. Their later retrospective
adjudication is in the updated manuscript; the old JSON is preserved as a historical record.
